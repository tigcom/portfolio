Tổng quan

Sixdo là nền tảng thương mại headless, trong đó backend REST Spring Boot cung cấp dữ liệu sản phẩm, danh mục cho storefront Next.js, với cấu trúc dữ liệu được quản lý theo version qua Flyway và API được bảo mật. Trọng tâm là trải nghiệm mua sắm nhanh, mượt và hợp đồng dữ liệu rõ ràng giữa hai tầng.

Vấn đề & Thách thức

Giữ dữ liệu danh mục nhất quán giữa backend và storefront server-rendered, quản lý trạng thái giỏ hàng giữa các phiên và bảo vệ API bằng Spring Security mà không làm chậm trải nghiệm.

Giao diện

API Danh mục & Thanh toán REST

Chuẩn hóa endpoint sản phẩm và danh mục, phục vụ luồng liệt kê, chi tiết và giỏ hàng trên storefront.

02

Quản lý tiến hóa cấu trúc dữ liệu bằng Flyway để mọi môi trường nhất quán và migration có thể lặp lại.

03

Storefront Server-Rendered

Tận dụng App Router và Server Components của Next.js để tăng tốc first paint và tối ưu hiệu năng.
