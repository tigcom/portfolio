# TEMPLATE PROMPTS — nơi paste prompt để tôi dựng mini-app

Dán prompt của từng template vào mục `### Prompt` bên dưới. Xong cái nào thì
**đánh dấu `[x]`** ở dòng tiêu đề (hoặc cứ paste xong nhắn "xong" cho tôi).

Mỗi template cần có đủ:
- **Nội dung từng trang** (nếu là app 4–5 trang thì mô tả từng trang; landing thì 1 trang).
- **Màu sắc / font / style** muốn (nếu prompt gốc đã có thì cứ paste nguyên).
- **Nội dung mock** (số liệu, tên, bảng, biểu đồ…) — UI thôi, không cần backend.

> Ghi chú: `furniture-showcase` (số 19) là template cũ giữ nguyên, **không cần prompt**.
